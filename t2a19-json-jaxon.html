05 — About JSON

JSON stands for JavaScript Object Notation. It is a lightweight format used to exchange information between websites, applications, and servers.

This project uses JavaScript's fetch() function to request information from an API. The response.json() method converts the response into a JavaScript object. Finally, JSON.stringify() formats the information so it can be displayed on the webpage.
