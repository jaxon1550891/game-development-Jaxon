🎨 What is CSS?

Cascading Style Sheets (CSS) is used to control the appearance and layout of a website.

CSS can be added to a website in several ways. A separate .css file is usually the best way to organize a larger website.

You can also use a <style> tag inside the <head> of a webpage.

Another option is inline CSS, which is written directly inside an HTML tag.
