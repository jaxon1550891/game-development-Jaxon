What is a JavaScript class?

A JavaScript class is a template for creating objects. Objects can store variables called properties and functions called methods.

  • Class: The blueprint for an object.
  • Constructor: Sets up a new object's properties.
  • Properties: Store information, such as a name or age.
  • Methods: Functions that perform actions.
  • this: Refers to the current object instance.

Example working class code

This is the class used by the interactive example:

class MyAnimal {
  constructor(passName, passAge) {
    this.myName = passName;
    this.myAge = passAge;
  }

  myShow() {
    return `Hello ${this.myName}! You are
${this.myAge} years old.`;
  }
}

const myDog = new MyAnimal("Snickers", 5);

console.log(myDog.myShow());

Notice: MyAnimal is the class, myDog is an object, myName and myAge are properties, and myShow() is a method.

Why use classes?

Classes make it easy to create many objects with the same structure but different information.
